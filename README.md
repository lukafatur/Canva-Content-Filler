# Text Populator

**Text Populator** is a Canva app that takes the copy-paste pain out of producing many text versions of the same design.

Collect every text element from your design into a spreadsheet, fill in as many variants as you need — translations, A/B copy, personalized messaging, per-market campaigns — then paste the table back to generate a finished page for each variant.

## Features

- **Collect** — pull every text element from the current page into a clean, numbered list (works across multiple pages).
- **Export** — copy the list as TSV (paste straight into Google Sheets or Excel) or download it as a CSV, formatted with `#` and `original text` columns.
- **Populate** — paste back a table with one column per variant and either:
  - **Auto-create pages** — clone the current page once per variant, fill in the text, and name each page after the column; or
  - **Apply manually** — apply any variant to a page you've duplicated yourself, with a report of any unmatched text.

## Use it for

- Localization (a page per language)
- A/B copy testing
- Personalization per audience or segment
- Multi-market rollouts
- Seasonal / promotional versioning

## Privacy

Text Populator runs entirely inside the Canva editor in your browser. It does **not** collect, store, or transmit any personal data, and makes no external network requests. See the [Privacy Policy](./PRIVACY.md).
